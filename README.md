# 👥 User Management System

## 📌 Task-3 | Full Stack Web Development Internship

This project is a **User Management System** developed as **Task-3** during my **Full Stack Web Development Internship**. The application allows users to register, log in securely, manage their profiles, and perform CRUD (Create, Read, Update, Delete) operations using **PHP** and **MySQL**.

---

## 🚀 Features

* 🔐 User Registration
* 🔑 Secure User Login
* 🔒 Password Hashing
* 👤 User Dashboard
* ✏️ Edit User Profile
* 🗑️ Delete User Account
* 📋 View User Details
* 🔄 Session-Based Authentication
* 💾 MySQL Database Integration
* 📱 Responsive User Interface

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/user-management-system.git
```

### 2. Move the Project

Copy the project folder into your **XAMPP** `htdocs` directory.

Example:

```
C:\xampp\htdocs\User-Management-System
```

### 3. Start XAMPP

Start:

* Apache
* MySQL

### 4. Create Database

Open **phpMyAdmin** and create a database:

```
user_management
```

Import the provided **users.sql** file.

### 5. Run the Project

Open your browser:

```
http://localhost/User-Management-System/
```
